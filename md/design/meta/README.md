# Meta

This part specifies how Sage's specification is written, rendered, checked,
and reviewed. It uses the same anchors, Rust associations, tests, and review
process as the compiler specification.

- [The book](book.md) defines chapter organization, the Crates explorer, and
  generated anchor pages.
- [The `.sage` language](language.md) defines modeled entities, semantic value
  types, and dependency envelopes.
- [Anchors and evidence](anchors.md) connects specification claims to Rust
  implementation excerpts and tests.
- [Architectural contracts](contracts.md) connects modeled operations to
  observed execution.
- [Reviewing implementations and tests](reviews.md) defines the committed review
  checklist and its freshness checks.
